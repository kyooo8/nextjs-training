- 該当コード:
  ```tsx

  ```

### S-4: [観点4] `getPostById` に `cacheTag` がない

- ファイル: `src/app/posts/actions.ts:81`
- 何がまずいか: `getPosts` は `cacheTag("posts")` でキャッシュされているが、`getPostById` はキャッシュなし。詳細ページは毎回サーバーで実行されるため、`deletePost` 後の反映は問題ないが、将来 `'use cache'` を付けたときにタグが抜けているとキャッシュ整合性が崩れる。現状は動作する。
- 修正案（キャッシュしたい場合）:
  ```ts
  export async function getPostById(id: number): Promise<Post | ""> {
    "use cache";
    cacheTag("posts");
    const post = posts.find((p) => p.id === id);
    return post ?? "";
  }
  ```
